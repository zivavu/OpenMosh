# Security

OpenMosh runs entirely in the browser. There's no server and no accounts, and your files never leave your machine. The only network requests are the feedback form (sent through Web3Forms), custom fonts you add from Google Fonts, and loading the app itself.

## Reporting a problem

Open a [regular issue](https://github.com/zivavu/OpenMosh/issues/new?template=bug.yml) with the steps to reproduce and the browser you used.

Only the version live at [openmosh.com](https://openmosh.com/) gets fixes.
